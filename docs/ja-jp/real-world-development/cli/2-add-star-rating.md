Copilot CLI をインストールして会話を試したので、次はプロジェクトに初めて変更を加えます。変更は小さくしましょう。ゲームのデータにはすでに星評価がありますが、ホームページのゲームカードには表示されていません。エージェントに評価を表示させ、変更を確認し、最初の pull request としてマージします。

このレッスンでは、次の操作を行います。

- 機能ブランチで、目的を絞った Copilot の会話を開始します。
- エージェントにプロジェクトの小さな変更を依頼します。
- `/diff` で変更を確認します。
- アプリを実行し、転送されたブラウザーで変更を確認します。
- 最初の pull request を作成してマージします。

## シナリオ

Tailspin Toys の各ゲームには星評価を設定でき、ゲーム詳細ページにはすでに表示されています。一方、ホームページのゲームカードに表示されるのは、タイトル、カテゴリ、パブリッシャー、説明だけです。練習として、既存の評価を各カードに表示するようエージェントに依頼します。これは小さく独立した変更なので、最初のセッションにぴったりです。

## 会話のしくみ

**会話**は、Copilot CLI を使ってタスクに取り組む場所です。Copilot アプリとは異なり、通常の CLI 会話では、専用の worktree を作成せず、ターミナルで現在チェックアウトされているリポジトリと Git ブランチを使用します。保存した会話に戻って同じやり取りを続けられますが、ファイルとブランチはディスク上の通常の Git 状態のままです。

会話では、プロンプトとエージェントの応答、ファイルを調査・編集する際のツール操作、そして `/diff` で確認できる変更の3つを扱います。

## 会話を開始して変更を依頼する

新しい会話を開始し、機能の実装に取りかかります。

1. Codespace に戻ります。
2. ターミナルが開いていない場合は、<kbd>Control</kbd>+<kbd>`</kbd>（Mac）または <kbd>Ctrl</kbd>+<kbd>`</kbd>（Windows/Linux）を押します。
3. まだ起動していない場合は、次のコマンドを実行して Copilot を起動します。

   ```bash
   copilot --yolo
   ```

4. スラッシュコマンド `/new` を実行して <kbd>Enter</kbd> を押し、新しいセッションを開始します。
5. 次のプロンプトで変更を依頼します。

   ```plaintext
   一覧ページのゲームカードに、各ゲームの5段階の星評価を表示してください。評価が null の場合は "No rating yet" と表示してください。カードのレイアウトはそのままにし、テストを追加して、関連するチェックを実行してください。
   ```

Copilot はプロジェクトを調査し、ゲーム詳細の表示に使われているファイルを特定して、必要なコードを作成します。これで Copilot CLI を使った新機能の追加は完了です。

## 差分を確認する

小さな変更であっても、AI が生成した変更はすべてマージ前に確認する必要があります。Copilot CLI 内で変更を確認しましょう。

1. `/diff` を入力し、変更されたすべてのファイルを確認します。
2. 評価がある場合は数値が、`starRating` が `null` の場合は `No rating yet` がゲームカードに表示されることを確認します。
3. どちらの状態もテストで確認されていることを確認します。
4. Copilot が実行したチェックの結果を確認し、失敗があれば修正を依頼します。
5. 確認が終わったら <kbd>Esc</kbd> を押して差分画面を閉じます。

> [!NOTE]
> Copilot を含む生成 AI ツールは決定的ではなく、確率に基づいて結果を生成するため、コードは毎回異なる場合があります。特定の実装と一致するかではなく、動作を確認してください。

## 変更を確認する

コードを読むだけで、正しく動作すると判断するべきではありません。Copilot にサイトを起動してもらい、Codespaces で転送されたブラウザーから更新後のユーザーインターフェイス（UI）を確認します。

1. Copilot にアプリの起動を依頼します。

   ```plaintext
   ブラウザーで星評価の変更を確認できるように、アプリを起動してください。URL を教えて、サーバーは実行したままにしてください。
   ```

2. Codespaces でポート `4321` が利用可能になったら、**Open in Browser** を選択します。
3. ゲームカードに5段階の評価が表示されていることを確認します。
4. Copilot に戻り、起動したサーバーを停止するよう依頼します。

   ```plaintext
   起動した開発サーバーを停止してください。
   ```

## 最初の pull request を作成してマージする

機能を実装できました。新しいコードをプロジェクトにマージするため、pull request（PR）を作成しましょう。

1. 既定のエージェントに変更をコミットするよう依頼します。

   ```plaintext
   レビュー済みの星評価の変更を、適切なコミットメッセージでコミットしてください。
   ```

2. `/pr create` を実行します。Copilot CLI は PR の作成時に既存のコミットを push し、PR の URL を表示します。
3. Copilot CLI が表示した URL を、<kbd>Command</kbd>（Mac）または <kbd>Ctrl</kbd>（Windows/Linux）を押しながら選択して PR を開きます。
4. 変更されたファイルとチェック結果を確認します。
5. 準備ができたら **Merge pull request** を選択し、マージを確定します。
6. Codespace に戻り、`/exit` で Copilot CLI を終了します。
7. ローカルの `main` を更新します。

   ```bash
   git checkout main
   git pull
   ```

- `/diff` で変更を確認しました。
