通过贴近实际的场景、完整应用和共享待办列表，探索 GitHub Copilot 在整个软件开发生命周期中的应用。你将以迭代方式规划修改、编写代码、测试行为、审查拉取请求，并使用代理管理工作。

## 场景

你是 Tailspin Toys 的新开发者。这是一家虚构公司，为桌游提供众筹服务，并采用开发者主题。团队的待办事项已作为 GitHub 问题提交，等待你领取。其中包括筛选和分页等功能工作，以及无障碍访问和编码标准等质量改进。

## 选择环境

无论你在哪里工作，都可以使用 GitHub Copilot。请选择最适合你开发方式的环境。每个工作坊都有自己的设置流程，并使用共享的 Tailspin Toys 场景。

### [GitHub Copilot CLI][cli]

在终端中使用代理式助手。通过 Plan 和 Autopilot 模式、说明、技能、自定义代理、Playwright MCP、Agent Merge 和实用斜杠命令完成工作。

### [GitHub Copilot 应用][app]

在桌面应用中运行并行代理会话、切换会话模式、协作处理画布，以及管理 GitHub 问题和拉取请求。

### [GitHub Copilot 云端代理][cloud]

将 GitHub 问题分配给异步代理，引导其工作、监视进度，并检查它创建的拉取请求。

### [Visual Studio Code][vscode]

在 Visual Studio Code 和 GitHub Codespaces 中使用 GitHub Copilot。无需离开编辑器，即可使用 Copilot Chat 代理模式、MCP 服务器和自定义代理。
